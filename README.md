# minigame-statePattern

### 흐름
```text
Title
  └─ 시작 선택
       ↓
    Battle
      ├─ 플레이어 턴: 공격 / 방어 / 회복
      ├─ 적 턴
      ├─ 적 HP 0 → Victory
      └─ 플레이어 HP 0 → GameOver
           ├─ Victory: 다시하기 / 종료
           └─ GameOver: 다시하기 / 종료
                └─ 다시하기 → Battle (체력 초기화)


PlayerTurn
  입력
    공격 → 적 HP 감소 → 적 사망? 이면 Victory
    방어 → 이번 피격 감소 플래그
    회복 → HP 증가
  끝나면 EnemyTurn

EnemyTurn
  단순 공격 (나중에 Strategy로 교체 가능)
  플레이어 사망? 이면 GameOver
  끝나면 다시 PlayerTurn
```
